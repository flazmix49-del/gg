# Auto EZ (Fabric 1.21.4)

Мод пишет в чат заданный текст (по умолчанию "ez") после убийства игрока.

- Меню: клавиша `\` по умолчанию (Настройки -> Управление -> Auto EZ, можно переназначить)
- В меню: вкл/выкл, текст сообщения, задержка
- Конфиг: config/autoez.properties

## Сборка
Нужна Java 21 и Gradle (или gradle wrapper):

    gradle build

Готовый мод: build/libs/autoez-1.0.0.jar -> положить в папку mods (нужен Fabric API).
